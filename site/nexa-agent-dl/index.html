NEXA Agent

nexa-agentlatest

NEXA with its own Node runtime: the same CLI and TUI as the npm package, for machines without Node or npm. One command installs nexa-agent and nexa into your home folder with no admin rights, and every download is checked against the release's SHA-256 list before anything is written.

  • macOS · Apple silicon & Intel
  • Linux · x64 & arm64
  • Windows · x64 (preview)

01Install

Pick your system. The installer detects the CPU, downloads the matching build, verifies its checksum and puts nexa-agent and nexa on your PATH.

terminal
$curl -fsSL https://downloads.agilekit.cc/nexa-agent-dl/install.sh | bash

Installs to ~/.nexa-agent and adds its bin folder to ~/.zshrc or ~/.bashrc. Add --no-modify-path after bash -s -- to leave your profile alone.

powershell
PS>irm https://downloads.agilekit.cc/nexa-agent-dl/install.ps1 | iex

Installs to %LOCALAPPDATA%\nexa-agent and adds it to your user PATH. No administrator prompt. Open a new terminal afterwards. Windows is a preview: the TUI is not supported there yet.

Then check it runs:

shell
$nexa-agent --version
$nexa doctor

nexa is the same program, so every command in the NEXA quick start works unchanged. If the npm-based NEXA CLI is installed as well, the nexa whose folder comes first in PATH runs.

02Activate

Activate the signed .license file supplied by your NEXA maintainer. Keep it private.

license file
$LICENSE_FILE="$HOME/Downloads/nexa.license"
$chmod 600 "$LICENSE_FILE"
$nexa license activate "$(tr -d '\r\n' < "$LICENSE_FILE")" && nexa license status

Do not commit, upload, paste, or attach the license to tickets or logs. The license lifecycle (revalidation, offline verdicts, moving to a new machine) is the same as for the NEXA CLI.

03Direct download

For offline machines or a managed rollout. The files belong to the release named at the top; SHA256SUMS lists the checksum of every file.

Verify a download before unpacking it, in the folder that holds both files:

macOS / Linux
$shasum -a 256 -c SHA256SUMS --ignore-missing
powershell
PS>(Get-FileHash .\nexa-agent-windows-x64.zip -Algorithm SHA256).Hash   # compare with SHA256SUMS

A browser download on macOS is quarantined by Gatekeeper and the bundled runtime is not notarized; the installer avoids that, so prefer it.

04Update and roll back

Run the installer again to move to the latest release. The three most recent versions stay on disk, so pinning an older one is fast. nexa upgrade updates the npm-based CLI, not this build.

macOS / Linux
$curl -fsSL https://downloads.agilekit.cc/nexa-agent-dl/install.sh | bash                          # latest
$curl -fsSL https://downloads.agilekit.cc/nexa-agent-dl/install.sh | bash -s -- --version 3.7.1   # pin
powershell · pin a version
PS>& ([scriptblock]::Create((irm https://downloads.agilekit.cc/nexa-agent-dl/install.ps1))) -Version 3.7.1

05Requirements

  • Nothing to install first. Node 22, ripgrep and the SQLite engine of the knowledge base ship inside the archive; no npm, no compiler.
  • macOS 11 or later on Apple silicon or Intel. An Intel terminal running under Rosetta still gets the Apple silicon build.
  • Linux x64 or arm64 with glibc 2.28 or later (Ubuntu 20.04+, Debian 10+, RHEL 8+), plus curl, tar and sha256sum or shasum.
  • Windows 10/11, 64-bit, PowerShell 5.1 or later. Preview: the CLI runs, the TUI is not supported yet. Windows on ARM uses the x64 build.
  • Alpine (musl) or another platform? Use the NEXA CLI, which installs with npm on Node 22.19+.
  • Corporate proxy: the installer uses your HTTPS_PROXY. Downloads come from github.com and objects.githubusercontent.com.

06Uninstall

macOS / Linux
$rm -rf ~/.nexa-agent   # then delete the "# NEXA Agent" PATH line from your shell profile
powershell
PS>Remove-Item -Recurse -Force "$env:LOCALAPPDATA\nexa-agent"   # then remove it from your user PATH
